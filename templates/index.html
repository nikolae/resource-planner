Getting Started

Projects

Use the dropdown in the top-left to switch projects or view all at once. Click + to create a new project, or the hamburger icon to manage and batch-delete projects.

Tasks

Click + Task to create one. Assign resources, set dates, pick a color, and group under a parent task. Click a task in the sidebar or double-click its bar on the chart to edit. Right-click a bar for a context menu.

Gantt Chart

Drag a bar to move it. Drag the edges to resize (cursor changes to indicate). The chart auto-expands when you drag past the visible range.

Use the horizontal zoom (Day / 3-Day / Week / 2-Week / Month) and vertical zoom (XS–XL) controls to adjust the view.

Dependencies

Hover a task bar to see connector circles at each end. Drag from a connector to another task to link them. The dependency type (FS, SS, FF, SF) is determined by which ends you connect.

Hover a dependency arrow to highlight it red, then click to delete. When a dependency is created, the successor automatically shifts to satisfy the constraint.

Resources

Click Resources to manage the resource list. Assign multiple resources per task with allocation percentages (e.g., a PM at 10%, an engineer at 80%).

Switch to Resources view to see one row per resource with all their tasks. Red overlays flag periods where a resource exceeds 100% utilization.

Sidebar

The sidebar is collapsible (arrow toggle) and resizable (drag the border). Column widths are also adjustable by dragging header borders. When collapsed, task bars show resource names inline.

Themes & Export

Click the palette icon to browse, create, edit, or duplicate themes with full color customization.

Click Export PNG to download the current view as an image for Confluence, slides, or email.
